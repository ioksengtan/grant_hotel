# 建築亮燈

手繪水彩建築的窗戶點燈模擬器，可切換台北圓山、APA 東京灣幕張與拉斯維加斯 Encore。

網站：https://ioksengtan.github.io/grant_hotel/

## 操作

- 繪製：點選或拖曳窗戶，切換亮燈、熄燈。
- 動畫：跑馬、呼吸、逐層亮起、閃爍、擴散。
- 文字：輸入文字播放窗戶跑馬。
- 方塊：按「開始遊戲」，把下落方塊排成整排即可消行。手機使用畫面按鈕；鍵盤以左右鍵移動、上鍵旋轉、下鍵加速、空白鍵直接落下、P 暫停。

方塊棋盤寬度為 10 扇窗。圓山 8 層為迷你挑戰，Encore 18 層、幕張 24 層。切換建築會重設遊戲；離開遊戲模式或切到背景會暫停。

建築插畫以真實照片作為參考，窗格配置為藝術模擬，並非實際房間測繪。案例來源見 `assets/buildings/SOURCES.md`。

## 開發

使用任意靜態網頁伺服器開啟本資料夾。無需安裝前端依賴。

遊戲規則測試：`node --test tests/tetris.test.cjs`。
